# Fonts

`InterVariable.woff2` is Inter 4.1 (variable, weights 100 to 900), by Rasmus Andersson, under the SIL Open Font License 1.1 (`OFL.txt`).

Source: the official release archive, file `web/InterVariable.woff2`
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

Self-hosted on purpose (D-041): no font CDN at runtime. `public/css/app.css` loads it with `font-display: swap`.
